# Focus Track

**Focus Track** is a productivity app built with SwiftUI and MVVM architecture, designed to help users stay organized and focused. It supports **iPhone** and **iPad**, adapting to **portrait**, **landscape**, and **dark mode**. With data persistence via **UserDefaults** and smooth animations, it offers an intuitive, efficient task management experience.

## Features

- **MVVM Architecture**: Clean separation of concerns using MVVM architecture to ensure scalability and maintainability.
- **Custom Data Model**: A well-structured data model to manage and persist tasks.
- **@EnvironmentObject**: Used to share app-wide data with views efficiently.
- **Data Persistence with UserDefaults**: User data (tasks) are saved and persisted using UserDefaults for easy retrieval across app launches.
- **Device Adaptability**: The app is optimized for both iPhone and iPad, and supports multiple orientations (portrait/landscape) and dark mode.
- **Animations & Transitions**: Smooth animations and transitions enhance the user experience and provide visual feedback.
- **App Icon & Launch Screen**: Custom app icon and a splash screen (launch screen) to improve the visual appeal.
